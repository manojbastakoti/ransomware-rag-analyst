# Security Policy

This project is intended for defensive cybersecurity research and operational support only.

## Supported versions

The project currently supports the latest branch on the main development line.

## Reporting a vulnerability

Please report suspected security issues privately through the project maintainer or repository security contact, rather than by opening a public issue.

Please include:

- a summary of the issue
- affected files or components
- reproduction steps or proof of concept
- the potential impact

We will review and respond as quickly as possible and coordinate a fix if the issue is valid.

## Safe use expectations

This project uses public advisories and defensive playbooks for educational and defensive purposes. Do not use it for malicious activity, lateral movement, or exploitation. Do not connect it to production systems without review and authorization.
